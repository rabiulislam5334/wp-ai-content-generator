# AI Content Generator (WordPress Plugin)

A simple custom WordPress plugin that demonstrates AJAX handling and AI-ready content generation inside the WordPress admin panel.

## 🚀 Features
- Admin panel UI for prompt input
- AJAX-based request handling
- Dynamic content generation (demo)
- Extendable with OpenAI API

## 🧠 How It Works
- User enters a prompt
- AJAX request is sent to WordPress backend
- PHP processes the request
- Response is returned dynamically without page reload

## 📦 Installation
1. Download or clone this repository
2. Upload the folder to `/wp-content/plugins/`
3. Activate the plugin from WordPress dashboard
4. Open "AI Generator" from admin menu

## 🔧 Tech Used
- PHP (WordPress hooks)
- AJAX (jQuery)
- WordPress Plugin API
